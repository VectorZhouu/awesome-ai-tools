# Contributing Guide / 贡献指南

Thank you for helping make this list better! / 感谢你帮助改善这个列表！

## How to Add a Tool / 如何添加工具

1. **Fork** this repository
1. Add the tool in the correct category table using this format:

```
| [Tool Name](https://url.com) | Short English description | 中文描述 | ✅/❌ |
```

1. Make sure the tool is:
- Actually an AI tool / 确实是 AI 工具
- Has a working URL / 链接有效
- Not already listed / 未重复收录
1. Submit a **Pull Request** with a clear title like: `Add [Tool Name] to [Category]`

## Guidelines / 规范

- ✅ = Has a free tier / 有免费版本
- ❌ = Paid only / 仅付费
- Keep descriptions concise (under 10 words) / 描述简洁（10字以内）
- Add tools to the most relevant category / 添加到最相关的分类

## Reporting Issues / 报告问题

If a link is broken or info is outdated, please open an Issue!
如果链接失效或信息过时，请提 Issue！
